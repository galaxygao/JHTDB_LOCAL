# 局部压力功率与速度平方重合统计

## 数据范围

数据集为 `isotropic1024coarse`，第 1 帧，物理时间 `t=0`。本次使用 12 个请求块，区域大小为 `768 × 256 × 64`，共 **12,582,912 个格点**。

索引范围：`x=[0,768)`、`y=[0,256)`、`z=[0,64)`。完整源网格为 `1024³`。使用前重新核验了 3,072 个压力梯度存储块的 SHA-256。

速度来自已校验缓存，压力梯度来自 JHTDB 的 `fd4noint` 方法，压力定义为 `P=p/ρ`。直接计算 `q = −u·∇P` 与 `u² = ux² + uy² + uz²`，未在裁剪区重新求导，也未做多 sigma 滤波。

**所有均值、RMS、阈值及统计均来自这个局部区域，不代表完整周期域。**

## 方向重合率与随机基准

$$A=\{q>\alpha q_{\mathrm{rms}}\},\qquad B=\{u^2>\beta\langle u^2\rangle\}.$$

A 只统计正压力功率事件；不是绝对值事件。阈值使用严格大于号。

N 为总格点数，N_A、N_B 为分别满足条件的格点数，N_AB 为重合格点数。

$$R(A,B)=\frac{N_{AB}}{N_A},\qquad R(B,A)=\frac{N_{AB}}{N_B}.$$

随机基准保持 A、B 格点数不变，假设它们在 N 个格点中均匀独立随机分布。这里使用解析期望，并未做保留结构形状的随机平移实验。

$$R_\pi(A,B)=\frac{N_B}{N},\quad R_\pi(B,A)=\frac{N_A}{N},\quad E[N_{AB}]=\frac{N_AN_B}{N}.$$

$$\widetilde R_{A\to B}=\frac{R(A,B)}{R_\pi(A,B)}=\widetilde R_{B\to A}=\frac{N_{AB}N}{N_AN_B}.$$

原始条件比例有方向性，各自除以对应随机基准后数值相同。随机归一化值大于 1 表示高于独立随机期望，不是统计显著性检验。

## 速度平方贡献

$$C_B=\frac{\sum_{i\in B}u_i^2}{\sum_i u_i^2},\qquad C_{\mathrm{excess}}=\frac{\sum_i\max(u_i^2-\beta\langle u^2\rangle,0)}{\sum_i u_i^2}.$$

C_B 包括选中格点的全部速度平方；C_excess 只计算超出阈值的部分。按单位质量动能 u²/2 计算，比例相同。

| beta | Threshold u2 | N_B/N (%) | C_B (%) | C_excess (%) |
|---:|---:|---:|---:|---:|
| 1 | 1.57499778 | 47.1797 | 76.4878 | 29.3082 |
| 1.5 | 2.36249667 | 23.9710 | 47.4520 | 11.4955 |
| 2 | 3.14999557 | 8.7844 | 21.4340 | 3.8652 |
| 3 | 4.72499335 | 0.8200 | 2.8007 | 0.3408 |

β=1 时，47.18% 的格点贡献了总速度平方的 76.49%；扣除阈值基底后，超出的部分贡献 29.31%。
